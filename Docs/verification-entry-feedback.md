# 轻账记 1.5.1（构建 26）交互验证

验证日期：2026-11-15。公开源码基线为 `e759326`，构建 26 的页面隔离改动基于 `cb63494`。商店现有版本为 1.5（20），本次提交版本为 1.5.1（26）。

## 修改

- 数字、运算、分类和步骤按钮复用并预热完整强度的 `.light` 触感生成器。
- 子分类在页内选择，选完直接进入详情；保留返回一级分类与重选，不再等待弹窗关闭或步骤滑动。
- 「记一笔」移到「关注分类」右侧，点击高度至少 48 点；保留空账本入口。
- 底栏底板、图标和文字保持固定，选中层仅水平移动，动画参数按用户要求设为 100 毫秒；保留拖动、取消回位、程序化跳转和减弱动态效果设置。
- 独立发布切页状态，四页由固定枚举输入的 `StableTabPage(...).equatable()` 隔离，避免切页重建所有直接持有 `@Query` 的页面。数据、会话和设置变化仍由页面自身观察，不缓存财务汇总。
- 日期分组、分类与趋势、预算汇总在单次渲染内复用。启动整理、远程变更合并、月份同步、前后台和时间变化由根视图管理；失败后返回明细仍会重试，正常切页不执行整批去重。

## 验证

- iPhone 完整 10 项 UI 回归通过，覆盖记账、子类重选、底栏点击/拖动、旋转、保存提示、月份共享、进入账本、删除撤销、外观与导出；导航用例使用 1118 条隔离模拟账目。
- 独立 iPad 动态数据用例的 48 个实际金额读数全部匹配：已有记录金额修改且条数不变、插入/删除/恢复、月份和账本切换、收入；统计页可见时立即更新，其他预热页面返回后显示最新值。分类详情与切页状态保留，真实窗口深色样式生效。
- 根层维护的两项隔离 UI 用例、32 条断言通过，覆盖启动一次、正常切页无维护、非明细页远程导入合并与去重、月份订阅同步、两类失败后的返回重试、显著时间变化及前后台恢复。
- 构建 25 的真实 iPhone 采样发现五个 121–166 毫秒主线程忙区间，每次同时更新明细、账本和预算。这些忙区间未采样到维护或订阅同步栈，支持继续隔离页面输入。
- 构建 26 的模拟器检查中，在 1118 条合成账目已预热、数据和环境均未改变、仅切换标签的情况下，四页包装和叶子 `body` 的执行次数均为 0；首次进入只执行目标页。此结果不表示数据或环境变化时也禁止刷新。
- 用户在真实 iPhone 体验构建 26 后反馈「响应满意」，并授权发布。100 毫秒是选中动画参数；本轮未取得有效的构建 26 真机点击到呈现时序，不将其表述为实测端到端延迟或帧率。
- 数据模型、迁移、分类维护、订阅计算及隐私配置未因本次交互修复改变；原数据与计算回归已覆盖旧数据迁移重开、金额精度、分期订阅、分类、CSV 与计算器。
- 真机安装继续使用原 CloudKit 容器及 `Production` 环境。构建 26 安装前后六类模型的行数与业务字段指纹一致，SQLite 完整性为 `ok`；指纹忽略 Core Data 的 `Z_OPT`。
- 无诊断代码的 1.5.1（26）归档与 App Store IPA 校验通过：分发签名有效，CloudKit 与 APNs 为生产环境，`get-task-allow` 为 false，隐私清单存在，无内存示例数据或临时时序探针。
- 商店截图使用十条隔离示例账目，更新记账入口及底栏；原生尺寸导出为无 Alpha 的 RGB 图片，不含真实财务数据。
- 真机业务数据备份、设备信息、签名、构建产物、测试结果与性能采样仅保留在本机私有目录，不进入公开仓库。系统禁止读取的启动快照缓存不作为业务数据备份的一部分。
