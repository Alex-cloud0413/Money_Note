# 1.1 开发验证记录

验证日期：2026-09-09。所有测试均使用模拟器示例数据或新建的临时数据库。

## 已通过

- Xcode 26.6 的 iOS 模拟器 Debug 编译及通用 iPhone Release 编译。
- 原 1.0 模型创建真实磁盘数据库后，迁移到 1.1：流水笔数、金额、备注、账户余额与关联、分类父子关系、预算及订阅保留；旧账默认属于生活账本。
- 账本、月份、收入/支出筛选互不混用。
- 子类占比涵盖未分子类数据，总和为 100%；空数据安全返回。
- 订阅生成的流水继承账本；重复同步不增加重复记录；修改订阅账本后其生成流水同步调整。
- 354 组分期边界：总额按分保持一致，没有零数或负数的有效分期。
- 迁移数据和新增账本／流水在进程重启后保留。
- iPhone 17 Pro / iOS 26.5 实际操作：输入 128，收起金额键盘，选择「餐饮 → 外卖」「事业账本」，填写备注后直接点顶部完成；事业账本出现金额 128 和对应备注，生活账本汇总不变。
- 统计页进入餐饮：子类金额 128、占本类 100.0%、占本月 21.5%，与当时事业账本总支出 595 一致。
- 自定义「旅行账本」创建后出现在账本总览。
- 深色模式首页与记账键盘可读；按钮文字对比度及底部遮挡修正已在模拟器检查。

## 发布前待验证

- 在保有旧账目的真机上验证升级和交互、深色模式与大字号，并由使用者确认视觉效果。
- 在授权的 Apple 开发者账户中确认 CloudKit Development 新字段／新实体，部署 Production Schema 后验证两台设备间同步以及旧版本导入行为。
- 签名、归档、TestFlight 和 App Store 发布尚未执行。

数据模型只新增可空归属字段和一个有默认值的账本实体，不删除或改名旧字段。CloudKit 的生产 Schema 部署与本地轻量迁移是不同步骤，参见 [Apple：Evolve your Core Data schema](https://developer.apple.com/videos/play/wwdc2022/10120/) 和 [SwiftData 跨设备同步](https://developer.apple.com/documentation/swiftdata/syncing-model-data-across-a-persons-devices)。
