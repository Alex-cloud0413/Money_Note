# 1.1 开发验证记录

验证日期：2026-09-09。自动化测试使用模拟器示例数据或新建的临时数据库；构建 4 另完成一次经用户授权的真机备份、覆盖升级及本机数据核验。

## 已通过

- Xcode 26.6 的 iOS 模拟器 Debug 编译及通用 iPhone Release 编译。
- 原 1.0 模型创建真实磁盘数据库后，迁移到 1.1：流水笔数、金额、备注、账户余额与关联、分类父子关系、预算及订阅保留；旧账默认属于生活账本。
- 账本、月份、收入/支出筛选互不混用。
- 子类占比涵盖未分子类数据，总和为 100%；空数据安全返回。
- 订阅生成的流水继承账本；重复同步不增加重复记录；修改订阅账本后其生成流水同步调整。
- 354 组分期边界：总额按分保持一致，没有零数或负数的有效分期。
- 迁移数据和新增账本／流水在进程重启后保留。
- iPhone 17 Pro / iOS 26.5 模拟器操作：输入 128，收起金额键盘，选择「餐饮 → 外卖」「事业账本」，填写备注后直接点顶部完成；事业账本出现金额 128 和对应备注，生活账本汇总不变。
- 统计页进入餐饮：子类金额 128、占本类 100.0%、占本月 21.5%，与当时事业账本总支出 595 一致。
- 自定义「旅行账本」创建后出现在账本总览。
- 深色模式首页与记账键盘可读；按钮文字对比度及底部遮挡修正已在模拟器检查。

## 构建 4 真机升级

- 在连接的 iPhone 17 / iOS 27.0 测试版上，以相同应用标识及开发者团队将 1.0（构建 2）覆盖升级为 1.1（构建 4）。安装前检查安装包签名和设备授权，安装后读回版本并确认应用启动后持续运行。
- 安装前经用户明确授权，将该应用数据备份到指定的本机目录；原备份保留，数据库完整性检查通过，并生成文件哈希清单。备份、校验副本和包含个人数据的明细结果均不进入仓库。
- 升级后的数据库完整性检查通过。逐项比较确认原有流水业务字段及账户归属、账户数据、预算、订阅、分类名称和父子层级保留；比较账户归属时按实际账户类型与名称匹配，兼容原有同步去重替换内部编号的行为。
- 纯黑配色与图标已在模拟器检查；真机安装和数据核验不代替使用者对界面及操作体验的确认。
