# 1.2（构建 5）设计审核修复与验证

对应上一版 Apple Design 审核的 D01–D18。保留纯黑、暖白与静态纸纹，使用系统导航、弹层及手势。

## 修复对应表

| 审核项 | 本版实现 |
| --- | --- |
| D01 主按钮不可见 | 统一主按钮组件，明确前景、背景、按下和禁用状态。 |
| D02 删除保护 | 普通账目移到最近删除，可撤销、重启后恢复；账户和分类归档；订阅管理分开停止与永久删除，永久删除显示影响笔数并确认。 |
| D03 分类改名关联 | 分类表单先编辑后保存，事务更新历史账目、订阅、预算和关注分类；旧名称支持延迟导入匹配；未知旧子分类可保留并编辑。 |
| D04 大字号 | 金额使用语义字号和完整横向阅读；辅助字号改为纵向信息行与两列分类，键盘支持滚动；不强制缩小主金额。 |
| D05 月份上下文 | 明细、账本、统计、预算共用月份；新账默认所选月份，保存后进入对应账本、月份并定位账目。 |
| D06 统计口径 | 日汇总明确为净收支；当前账户余额排除未来日期；未来记录标记计划；预算默认只设置所选月份，旧预算保留为重复规则。 |
| D07 账本路径 | 进入账本直接打开明细；订阅显示当前账本并可切换；资金账户明确跨账本共用。 |
| D08 记账密度 | 常用分类四项、全部分类单独选择；账户与账本有独立标签；顶部完成持续可用。 |
| D09 验证说明 | 算式、金额、分期下限、名称冲突、初始余额均有可理解原因，无效输入不自动变为零。 |
| D10 草稿与结果 | 新账本机草稿可恢复；编辑表单有未保存保护；保存成功反馈、账目定位及删除撤销。 |
| D11 统计层级 | 分类金额与有标签的比例条优先；大类→子类→具体账目使用原生导航；月份趋势有明确读屏月份和金额。 |
| D12 自定义图标 | SF Symbols 选择器与实际图标显示一致；兼容旧 emoji，改名不再决定已选择的图标。 |
| D13 可访问性 | 月份、账本、删除与添加入口有明确标签；当前选择与金额可读；操作目标至少 44 点；装饰元素不参与读屏。 |
| D14 宽屏与横屏 | iPad 宽屏明细采用汇总/流水双栏，统计图表与列表并列；手机横屏键盘与表单左右分区。 |
| D15 数据反馈 | 系统真实同步事件、最近保存状态；显式准备 CSV 并处理写入失败；存储打开失败显示重试页并保留原文件。 |
| D16 视觉规范 | 统一纸面卡片、表单、列表、金额字体、月份控件与按钮，修正大字号的间距与边界。 |
| D17 App 图标 | 保留账本轮廓，以单一 ¥ 记账符号替代勾；分别提供浅色、深色、着色资源。 |
| D18 动效与触感 | 保留系统可中断交互，自定义位移尊重减少动态效果；成功/失败触感仅随真实结果触发，成功提示可读屏。 |

## 数据结构

在原结构上仅增加可空字段：账目 `deletedAt`、账户/分类 `archived`、分类 `previousNames`、预算 `monthKey`。旧值为 nil 时保留原意。保留 `bookID` 的旧版生活账本解释及原有关系。
