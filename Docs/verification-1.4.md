# 1.4（构建 9）明细、导出与视觉更新验证

本版在 1.3 的账本与三步记账基础上，优化明细信息层级、筛选导出和全局纸张视觉，不改变数据模型或既有账目语义。

## 产品变化

- 明细：删除计划账目提示及其分隔线，移除当月结余，保留支出、收入和按日期倒序的流水。
- 今日支出：在关注分类下显示当天支出合计与明细，可直接进入原账目编辑。
- 关注分类：从页内展开改为独立弹窗，入口居中，继续按当前账本和月份汇总。
- CSV：导出前可选择月份、账本和全部/支出/收入，最近删除仍不进入文件。
- 视觉：浅色模式改为纯白微皱纸张底，减少圆角卡片和装饰色，以黑色文字、细线和留白建立层级。
- 记账：进度、金额键盘、分类、详情、底部操作和右滑返回统一为更直接的反馈。
- 图标：纯白底与纯黑记账本，图形实际像素边界约占画布 61%；深色和系统着色资源保持相同比例。

## 自动验证

- `Tests/run-checks.sh` 全部通过：旧数据库迁移与重开、账本/月/收支隔离、子分类统计、354 组分期边界、订阅精度与幂等、分类改名与恢复、独立月度预算、计算器和 CSV 转义。
- Debug 模拟器构建通过；新版图标在模拟器主屏验证，圆角遮罩下无裁切。
- Release 真机构建、签名、安装与启动通过。
- 真机安装前后 SQLite 完整性均为 `ok`，业务表逐表哈希一致：575 笔账目、70 个分类、5 个订阅、3 条预算及 3 条不可见旧账户兼容数据全部保留。
