# 1.3（构建 6）交互调整与验证

本版聚焦实际记账路径：移除账户产品概念，把新建与编辑账目改为三个连续步骤，并让每个月的预算完全独立。

## 产品变化

- 账户：账本、记账、订阅、最近删除、设置与 CSV 中不再出现账户入口、余额、选择或字段。
- 兼容：旧账户实体和关系仅作为不可见的存储迁移壳保留；新版本不创建、不展示、不写入账户信息，避免已有 SwiftData/CloudKit 数据因直接移除模型而无法打开。
- 记账：第一步输入收支类型与金额；第二步先选一级分类，再选子分类或明确选择「不分子类」；第三步选择账本、日期、备注与分期，最后完成。
- 返回：第二、三步都提供「上一步」，输入与选择完整保留；取消或下拉关闭仍受草稿保护。
- 动效：前进与返回沿相反方向切换，响应「减少动态效果」时改为淡入淡出。
- 稳定性：iCloud 与持久化存储通知统一回到主线程更新界面，避免同步期间偶发空白页。
- 预算：总预算和分类预算都只属于当前账本的当前月份，不再创建或继承每月重复规则。
- 旧预算：旧版无月份的固定预算只迁移到升级所在月份；若当月已有明确设置，以当月设置为准，旧数据仍保留为迁移记录。
