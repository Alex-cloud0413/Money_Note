# 1.4.2（构建 12）设置交互修复验证

本版修复导出月份切换与设置页外观更新，不改变数据模型或账目语义。

## 修改

- `MonthPicker` 明确使用独立按钮样式，避免在 Form 行内一次点击同时触发前后两个动作。两个箭头的标签均保留完整 44×44 点点击区域。
- 外观设置应用到应用窗口，使已打开的设置弹窗立即响应浅色、深色及跟随系统。跟随系统时恢复系统管理，不缓存上一次强制外观。
- Release 使用独立 entitlement 文件，将 `com.apple.developer.icloud-container-environment` 明确设为 `Production`；签名私钥、描述文件不进入仓库。

## 验证

- 在 iPhone 17 / iOS 26.5 模拟器上复现原版两个问题。
- 最终版本的两项 XCUITest 回归测试全部通过，0 失败。
- 月份测试覆盖前后切换、连续向前三个月、44×44 点点击范围及按钮边缘点击。
- 外观测试保持设置页打开，验证浅色→深色→浅色→深色→跟随系统，使用截图亮度与页面仍打开的断言检查即时更新。
- 原工程 Release 编译、真机签名、覆盖安装及启动通过。
- 真机安装后首次启动前与启动后的数据库完整性均为 `ok`，有效账目数量与用户提供的安装前基线一致，全部账目业务字段指纹在首次启动前后保持一致。
- 最终真机签名明确使用原有 CloudKit 容器及正式环境；启动后的 CloudKit 导入、导出事件均成功，无错误码。
- 模拟器验证使用独立应用标识及 `--preview-data` 内存样例数据。
- `git diff --check` 通过。设备数据库、财务数据、签名文件及测试截图仅保留在本机备份目录。
