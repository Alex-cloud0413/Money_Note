# iPhone Duo 展示截图

三张图片来自 iOS 27.1 iPhone Duo 模拟器的闭合外屏，实际分辨率为 1398×2034。仅将原始 PNG 编码为无透明通道的 JPEG，未重绘界面或合成设备。

- `01-details.jpg`：明细。
- `02-statistics.jpg`：统计。
- `03-budget.jpg`：预算。

应用以 Debug `--preview-data` 启动，使用隔离的内存示例账目，不包含真实财务数据。此组图片只证明外屏的展示效果，不代表内屏、半折或真机已经验收。

尺寸依据：[Apple 截图规范](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)。
